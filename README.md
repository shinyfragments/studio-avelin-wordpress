# Studio Avelin WordPress

Local working repository for the Studio Avelin WordPress child theme and static experiments.

## Live paths

Child theme:
`wp-content/themes/studio-avelin-child/`

Experiments:
`wp-content/experiments/`

Current experiment:
`/experiments/matrix/`

## Workflow

1. Edit locally in VS Code.
2. Commit changes to Git.
3. Push to GitHub.
4. Upload changed files manually via Cyberduck/SFTP.
